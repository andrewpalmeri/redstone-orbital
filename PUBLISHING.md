# Redstone Orbital — publishing policy

**Nothing auto-publishes.**

1. New briefs are staged as drafts (`draft: true`, `status: pending_approval`) in the authoring workspace.
2. Draft and example/placeholder posts are **not** deployed to this site.
3. Only an explicit human approval runs `approve_and_publish.py`, which clears the draft and pushes this GitHub Pages repo.
4. Social posts (X / LinkedIn) are never sent by the staging scripts; outbox copy is prepared after approval only.

Live site: https://redstoneorbital.com
